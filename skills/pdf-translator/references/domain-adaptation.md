# Domain adaptation

Read this reference when the source is legal, regulatory, medical, scientific,
financial, technical, academic, commercial, or safety-critical rather than
plain general prose.

## Translation precedence

Use terminology in this order:

1. User-provided glossary, style guide, or approved previous translation.
2. Official bilingual names, cited standards, and document-defined terms.
3. Consistent usage already established in the source document.
4. Conventional target-language terminology appropriate to the domain.

Do not silently replace a source term merely because another term sounds more
natural. Preserve defined terms, labels, identifiers, and capitalization.

## Domain safeguards

| Domain | Preserve and avoid |
| --- | --- |
| Legal / regulatory | Preserve clause numbering, defined terms, modal force, dates, jurisdictions, signatures, and seals. Do not provide legal advice or alter obligations. |
| Medical / scientific | Preserve measurements, species/drug names, endpoints, uncertainty, citations, and statistical notation. Do not infer diagnoses or clinical conclusions. |
| Financial / commercial | Preserve currencies, decimal separators, dates, accounting labels, legal-entity names, and transaction references. Do not round or normalize values. |
| Technical / engineering | Preserve units, tolerances, part numbers, commands, warnings, diagrams, and safety language. Use target-language standards only when source meaning is unchanged. |
| Academic | Preserve citations, quotations, equations, figure/table references, and hedging. Do not translate a cited work's official title unless the source does. |
| Marketing / general business | Preserve brand names, product names, calls to action, and audience intent; localize tone only within the user's requested style. |
| Forms / certificates | Preserve field order, blanks, stamps, signature areas, and identifiers. Never invent missing values. |

## Names, dates, and uncertainty

- Use an official spelling or transliteration when the source, user, or an
  established bilingual reference provides one. Otherwise choose one reasonable
  transliteration and use it consistently.
- Retain source dates, amounts, codes, and units exactly unless the user asks
  for localized formatting. If changing presentation, retain the original
  unambiguously where legal, financial, clinical, or operational use requires it.
- Use red uncertainty markup only when the user requests it or when a missing/
  illegible source value materially affects meaning. Otherwise put a concise
  translator note in the handoff rather than altering the document's visual tone.
